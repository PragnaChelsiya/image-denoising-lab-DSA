# Image Denoising and Comparison Lab

A Streamlit frontend and PyTorch backend that runs an image through a trained convolutional Variational Autoencoder (VAE): encoder → latent vector → decoder. Gaussian noise can be injected before encoding.

## Requirements
- Python 3.10–3.12 recommended
- Internet connection for the first-time CIFAR-10 training data download
- CPU works; an NVIDIA GPU can speed training up

## Windows setup (PowerShell or Command Prompt)

1. Extract the ZIP and open a terminal in the `image_denoising_lab` folder.
2. Create and activate a virtual environment:

   ```bat
   py -3.11 -m venv .venv
   .venv\Scripts\activate
   python -m pip install --upgrade pip
   ```

   If `py -3.11` is not available, use `python -m venv .venv` with an installed supported Python version.

3. Install dependencies:

   ```bat
   python -m pip install -r requirements.txt
   ```

   If PyTorch installation fails, use the official selector at https://pytorch.org/get-started/locally/ and select Windows, Pip, Python, and CPU (unless you specifically need CUDA).

4. Train and save the model. This downloads CIFAR-10 the first time:

   ```bat
   python train.py --epochs 5 --limit 20000
   ```

   Wait for `Saved trained model to checkpoints/vae_cifar10.pt`. Do not close the terminal during training. Training time depends on your computer. For a quicker smoke test, use `python train.py --epochs 1 --limit 2000`, but quality will be lower.

5. Start the app:

   ```bat
   python -m streamlit run app.py
   ```

   Streamlit prints a local URL, usually http://localhost:8501. Open that URL in your browser. Keep the terminal open while using the app.

6. Run the model tests (optional but recommended):

   ```bat
   python -m pip install pytest
   python -m pytest -q
   ```

## How to use
- Upload a PNG/JPG/JPEG.
- Select the latent dimension that matches the trained checkpoint.
- Move the Gaussian noise slider.
- Click **Run comparison**.
- Inspect original, noisy, reconstructed images and MSE/PSNR. Download the reconstruction if needed.

## Important technical notes
- Model input is converted to RGB and resized to 64×64 to match the model architecture. This resize is only input preparation; the output is generated by the VAE decoder.
- The saved checkpoint is genuinely trained by `train.py` on CIFAR-10. A freshly trained model may reconstruct unrelated high-resolution photos imperfectly because CIFAR-10 consists of small natural images.
- The latent dimension changes the bottleneck size. To change it, retrain using `python train.py --epochs 5 --limit 20000 --latent-dim 64` (or 32), then select that same dimension in the app.
- Noise is added to the image tensor before encoding. The current model is trained as a standard VAE, not specifically as a denoising VAE; it can reduce some noise but denoising quality is not guaranteed. For a strong denoising experiment, train with noisy inputs and clean targets.
- MSE is computed between the original 64×64 input and the reconstructed image in [0,1] range. Lower MSE indicates closer pixel values.
- The first training run requires internet to download CIFAR-10. The app itself can run offline after the checkpoint exists.

## Troubleshooting
- `No module named streamlit/torch/torchvision/PIL`: activate `.venv` and run `python -m pip install -r requirements.txt`.
- `Trained model not found`: run `python train.py ...` and check for `checkpoints/vae_cifar10.pt`.
- Port 8501 already in use: run `python -m streamlit run app.py --server.port 8502`.
- If `torchvision` installation fails, use the official PyTorch installation selector and make sure `torch` and `torchvision` versions match.
